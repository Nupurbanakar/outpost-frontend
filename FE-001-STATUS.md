## Next Steps (After Node Upgrade)

### 1. Install Dependencies
```bash
cd ~/Desktop/outpost-frontend
npm install
```

### 2. Create Project Structure
```bash
mkdir -p src/api src/components/ui src/pages src/hooks src/contexts src/types src/utils src/styles
```

### 3. Create Vite Configuration
Create `vite.config.ts`:
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
      },
    },
  },
})
```

### 4. Create TypeScript Configuration
Create `tsconfig.json` (Vite template provides this)

### 5. Configure Tailwind CSS
```bash
# After npm install
npx tailwindcss init -p
```

Create `tailwind.config.js`:
```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

### 6. Create src/styles/globals.css
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### 7. Create Basic App Files
- `index.html`
- `src/main.tsx`
- `src/App.tsx`
- `src/vite-env.d.ts`

### 8. Configure ESLint & Prettier
(Files will be generated by Vite template)

### 9. Run Dev Server
```bash
npm run dev
```

App should be at: http://localhost:5173


```bash
# Check Node version
node --version  # Must be 18+

# Check if port 5173 is available
lsof -i :5173
```
